# 风

**[wind.archein.site](https://wind.archein.site/)**

每天一段。读完就走。

---

这是一个只有一个功能的网站：每天给你一段公版的哲学文字。中文古籍是原文，西方的段落带原文，旁边横躺着一行希腊文、拉丁文或德文。没有进度，没有打卡，没有"下一条"。右下角只有"昨日"——可以回头，不能预支。

它不是产品，是我自己想每天打开一次的东西。做它的时候我定了几条规矩，写在这里，也是写给以后的自己。

## 每天只有一段

我有一个阅读计划的网站，很认真，有栏目、有索引、有进度。这个站是它的反面。计划是往前赶的，这里不往前赶：一段读完，页面上就没有别的东西可看了，你只能关掉它。

限制不是为了克制，是为了让那一段文字有分量。同一句「致虚极，守静笃」，在一个列表里和在一整张空白的页面上，不是同一句话。

## 竖排

中文古文本来就是竖着写的。把「夫大块噫气，其名为风」竖排、从右往左读，它自然就慢下来了——一行字变成三四列，眼睛要走一段路。网页上几乎没人这么做，因为麻烦；但这些文字在横排里已经待了一百年，让它们回去一次不过分。

西方的段落是自译，标了"试译"。译文旁边横躺着一行原文，一是诚实——读者知道这是转述，不是译本；二是好看——一行侧着的希腊文靠在竖排的中文旁边，是这个站我最喜欢的一处。

手机上改回横排。竖排在手机上要横着滚，不值得。

## 风听文字的话

页面后面有一个风场：上千条细线沿着噪声流场从右向左流，像宣纸上被吹开的墨丝。它绕开中间那块文字，留一片静处。

风随三样东西变。季节：秋风长而急，冬风稀而利，春天有一点向上的浮力，夏天几乎不动。时辰：清晨偏青，白天月白，黄昏偏紫，入夜是玄色。还有段落本身——每一段可以带一个风量：「致虚极」那天风几乎停，「大块噫气」那天满屏都是风，「独钓寒江雪」是冬天稀疏的几缕。

字是被风带来的。每个字从右上方沿风向落位，远近不一、角度不一，落款最后浮现。换日的时候，当前的字被吹走，昨天的字从右边吹进来。你可以用指针拨开风，按住起风，点左下角的「风」字起一阵大的。右下角的「声」是实时合成的风声，默认关着。

动效的多少不是审美的变量，"是否服从同一个逻辑"才是。这个页面里能动的东西不少，但每一样都是风在动，所以不乱。我砍掉过卷轴的微微摆动和「风」字的呼吸——它们看着有理，但风解释不了它们。

## 没有的东西

没有账号、没有收藏、没有分享按钮、没有"你已连续阅读 N 天"。没有推荐算法：哪一天出哪一段，由日期决定，对所有人一样。没有 Google Fonts，字体自托管。没有任何统计。

## 结构

```
data/passages.json   文本。east 是中文古籍原文，west 是西方公版原文 + 短句自译
src/index.html       页面模板
build.py             注入文本、切字体子集，生成 dist/
fonts/               放 LXGWWenKai-Light.ttf（不入 git，28 MB）
dist/index.html      成品；dist/fonts/feng.woff2 是字体子集，约 330 KB
```

## 构建

```bash
# 字体（一次）：https://github.com/lxgw/LxgwWenKai/releases → LXGWWenKai-Light.ttf → fonts/
pip install fonttools brotli
python3 build.py            # 部署用：index.html + fonts/feng.woff2
python3 build.py --inline   # 单文件：字体内嵌，约 500 KB
```

没放字体也能 build，会退回 Google Fonts 的 Noto Serif SC。字体子集按全部段落用到的字切，加字之后重新 build 就行。

## 加一段

```json
{ "t": "正文，换行用 \n", "s": "出处",
  "n": "试译（中文原文则删掉）", "o": "原文（可选）", "l": "原文语言 grc/la/fr/de/da/en/ja（可选）",
  "w": 0.3, "season": "winter" }
```

- `w`：这一段的风量。0 近乎无风，1 是季节默认，1.5 大风。不写就 1。
- `season`：spring / summer / autumn / winter。写了就只在那个季节出现，不写全年可出。

放进 `east` 或 `west`。east 与 west 按 3:2 交错，东方在前。
